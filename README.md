# Study_Skills

面向真实项目问题的结构化学习与发布仓库。

本仓库将技术问题整理为可复用的学习材料，并通过 `skills/learning-page-design-publisher` 发布到 GitHub Pages。

- Canonical lessons: `skills/learning-page-design-publisher/lessons/`
- Pages data: `docs/_data/lessons/`
- Pages entries: `docs/lessons/`
- Shared / lesson-specific layouts: `docs/_layouts/`
- Publishing and QA tools: `tools/`

当前课程包括软件工程、前端工程、软件交付、Git、网络与云基础等主题。
