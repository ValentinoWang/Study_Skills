# 几何规则与覆盖范围

共享浏览器实现：tools/learning_figures/browser.js。所有 PASS 都受下列范围限制。

| 规则族 | 失败与修复 | 正常例外 / 支持边界 |
|---|---|---|
| FIG-MODEL-001 | 无效引用、重复ID、错误after、模型结果不符；先修事实 | 独立读取不强造固定因果 |
| FIG-CONTENT-001 | 图前定义缺失/晚出/隐藏；补可见绑定 | 纯日常语言总览无需先背词典 |
| FIG-COVERAGE-001 | 新对象未登记、预期对象删除/隐藏；补清单或恢复 | 不是只有 data-protect 才检查 |
| FIG-GEOM-001 | 独立文本占位过近；换行/分行/扩大空间 | 同一 text 的 tspan 按整体处理 |
| FIG-GEOM-002 | 文本与非所属节点/描边/箭头碰撞；重排 | 所属节点与祖先包含合法 |
| FIG-CONTAIN-001 | 子对象越出父框、文字内边距不足 | 箭头终点接触目标端口合法 |
| FIG-READ-001 | 最终字号/边缘留白不足；用窄屏步骤或局部滚动 | 不把源 font-size 当显示字号 |
| FIG-A11Y-001 | 主要文字对比度不足；提高对比 | 颜色+文字冗余允许 |
| FIG-INTEGRATION-001 | 错插入、重复DOM ID、窄屏丢事实、根溢出 | 局部图滚动允许 |
| FIG-ARTIFACT-001 | 源/派生/检查产物不匹配；重建并重验 | QA记录放产物外 |

## 几何解释

getBBox 本地边框通过 getScreenCTM 统一到 CSS 坐标；不能把 SVG单位、CSS像素、截图物理像素混比。
只支持轴对齐的正向缩放/平移；旋转、斜切、反射、不支持图元返回 BLOCKED。
多行 text 是一个 label；所有实际可见文本都遍历，与 expected 清单双向核对。
同样核对节点、line、显式 polygon 箭头与辅助泳道，防止改 path 或标成装饰绕检。

线条占位含 stroke，箭头显式多边形单独检查。自身父节点包含合法；消息标签侵入别的结果卡非法。
当前采用保守包围盒和受控图元，不声称像素级字形遮挡的完备证明。圆角等疑似相交可能保守拒绝。
阴影、复杂裁切、自由路径的第三方 SVG 不可拿空检查结果冒充通过。
历史 red SVG 的 legacy 审计只用于重现遮字，绝不作为允许旧图绕过 v2 对象覆盖的发布入口。

## 初值，不是行业统一标准

见 profiles/readable-v2.json：标签16CSSpx下限，标签间8px、非所属节点12px、箭头8px，
自身内边距16×12px，画布16px，浮点容差0.5px。数值按最终呈现尺度判断。
文本对比度检查4.5:1；非文本描边、颜色语义与整体视觉层级仍需审阅，不能宣称全WCAG认证。

## 必留测试

历史两图原始字节固定为红例；缺保护框仍报错。另有合法包含/多行/归属图绿例。
注入漏标、删字、隐藏、错误owner、节点遮字、文本重叠、超粗线、放大箭头、path逃逸、变换、缩小、低对比。
每条报错含对象ID与可执行修复方向。不得更新红例掩盖缺陷，也不得自动批准截图基线。

技术依据：W3C SVG2 rendering、coords#BoundingBoxes、types#InterfaceSVGGraphicsElement；
CSS Font Loading document.fonts.ready 仅用于布局同步，不等同目标字体全部字形加载成功。
