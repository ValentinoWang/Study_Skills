## 两小时路线

| 时间 | 主线 | 核心问题 |
|---|---|---|
| 0—10 分钟 | 宏观地图 | 页面、业务、数据和运行环境是什么关系？ |
| 10—30 分钟 | 界面与请求 | 组件、状态、布局、HTTP 与错误恢复如何串起来？ |
| 30—50 分钟 | 数据与业务状态 | 怎样防止写一半、并发覆盖和旧版本丢失？ |
| 50—65 分钟 | 身份、权限与租户 | 怎样证明这个人能改这份计划？ |
| 65—85 分钟 | 异步、支付与计费 | 超时、重复通知、退款和额度怎样分别处理？ |
| 85—100 分钟 | 小程序与手机 | 离线、锁屏、系统权限、推送、版本兼容如何影响设计？ |
| 100—110 分钟 | 开发、验证与发布 | 测试、验收、部署与线上读回分别证明什么？ |
| 110—120 分钟 | 综合排错 | 对越权、覆盖、重复入账等六个问题建立验证方案。 |

每条主线包含前置概念、术语解释、机制、场景、失败边界、小题与参考答案。全课另有 12 个全局术语卡、51 个官方或标准文档入口、三级提示和实际综合答案。首轮不要求运行示例代码；选读内容不计入两小时预算。
